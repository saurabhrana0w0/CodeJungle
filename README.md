## Folder Organization
Each language directory contains:
- `experiments` Small tests, prototypes, and explorations.
- `notes` Chapter-by-chapter examples and learning notes.
- `projects` Mini-projects created while learning.
- `README.md` Language specific documentation and setup instructions.

## Goals
- Practice programming fundamentals.
- Explore different programming languages and tools.
- Build small projects consistently.
- Track my learning progress.
- Keep useful examples for future reference.

## Getting Started
Choose a language directory and read its `README.md` file for language-specific instructions. Some projects may include their own dependencies or setup requirements. Refer to the project documentation before running them.
